# Bobyemi Limited MVP

# Vision

To build a centralized digital operations platform that helps Bobyemi Limited manage financial services, repair workflows, staff activities, and customer communication efficiently.

---

# Core Problems

The business currently relies heavily on:
- notebooks,
- WhatsApp communication,
- manual tracking,
- memory,
- and fragmented records.

This creates operational challenges such as:
- missing transaction records,
- poor customer tracking,
- inconsistent repair workflow,
- limited business reporting,
- and reduced operational efficiency.

---

# MVP Goal

The MVP aims to:
- digitize operations,
- centralize records,
- improve accountability,
- improve customer communication,
- and modernize daily business workflows.

---

# Target Users

## Internal Users
- Owner/Admin
- Manager
- Staff
- Technicians

## External Users (Future)
- Customers
- CCTV clients
- BetKing agents

---

# MVP Scope

## Module 1 — Authentication

Features:
- Login
- Logout
- Role-based access

Roles:
- Admin
- Manager
- Staff
- Technician

---

## Module 2 — Transaction Management

Supported services:
- OPay deposits
- OPay withdrawals
- Electricity recharge

Features:
- Record transaction
- Search transactions
- View transaction history
- Daily transaction totals
- Staff transaction tracking

---

## Module 3 — Repair Management

Features:
- Register repair request
- Track repair status
- Assign technician
- Update repair workflow
- Pickup confirmation

Repair statuses:
- Received
- Diagnosing
- Repairing
- Ready for Pickup
- Delivered

---

## Module 4 — Notifications

Notifications:
- Repair received SMS
- Repair ready SMS
- Thank-you messages
- Email notifications

---

## Module 5 — Dashboard

Dashboard metrics:
- Daily transactions
- Repair statistics
- Staff activity
- Revenue estimates

---

# Non-MVP Features (Future)

The following features are intentionally excluded from the MVP phase:

- OPay API integration
- Automated utility payments
- Inventory management
- Accounting system
- Mobile application
- Customer portal
- CCTV contract workflow
- BetKing management portal
- Analytics engine
- AI automation

---

# Success Metrics

The MVP will be considered successful if:
- staff can use it daily,
- transactions are digitally recorded,
- repairs are trackable,
- notifications work reliably,
- and management can monitor operations remotely.

---

# Development Approach

The project will follow:
- agile iteration,
- modular architecture,
- feature branching,
- continuous documentation,
- and scalable development practices.
